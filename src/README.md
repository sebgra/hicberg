# Pixi installation

## Installing Pixi

To install Pixi environment manager

```bash
curl -fsSL https://pixi.sh/install.sh | sh
```

### Installing env

```bash
pixi isntall 
```

### Running Hicberg

```bash
 pixi run hicberg --version
```

# UV installation

## Installing UV

```bash
curl
 -LsSf https://astral.sh/uv/install.sh | sh

```

### Installing venv

```bash
uv sync
```

### Running Hicberg\

```bash
uv run hicberg --help
```
